**Arise by INFINITAS · Senior Software Engineer · May 2024–August 2026**

## Overview

At Arise by INFINITAS, a subsidiary of Krungthai Bank, I worked on the backend services supporting user onboarding and bank account opening in the **CLICX mobile banking app**. My responsibility extended from API design and implementation through go-live and production support.

## My role

- Led a **five-person software engineering team** designing and implementing the backend services and APIs for both customer journeys.
- Built services using **Go, Kafka, Redis, MongoDB, and PostgreSQL**.
- Owned the API lifecycle, including **go-live, production monitoring, and incident investigation**.
- Deployed services on **Kubernetes with ArgoCD** and used **Prometheus and Grafana** for production monitoring.

## Performance improvements

I improved caching and optimized MongoDB indexes for per-user onboarding documents. These changes reduced response latency across the onboarding APIs from approximately **2 seconds to 20 milliseconds**.

This work brought together backend development, database performance, and production operations: the same team that implemented the customer journeys also supported their behavior after launch.

## Technologies

**Backend and data:** Go, Kafka, Redis, MongoDB, PostgreSQL.  
**Deployment and monitoring:** Kubernetes, ArgoCD, Prometheus, Grafana.
