**Data Science and Engineering Project · May 2022**

## Problem

This project used radar and wind data from the Thai Department of Drainage and Sewerage (DDS) to build a real-time rainfall nowcasting system for Bangkok.

## My contribution

- Built an end-to-end data pipeline and dashboard with **Google Cloud Functions, Pub/Sub, Cloud Storage, Folium, and Power BI**.
- Led the team in training and developing **optical flow, ConvLSTM, and RainNet (autoencoder)** models with **TensorFlow and Keras**.
- Connected data collection, forecasting, and visualization in a single system.

## Result

The project reported **mean squared error below 0.001** on the DDS radar and wind data used in the study. This result is specific to the project's data and evaluation setup; it is not a standardized benchmark comparison.

**Tools:** Python, TensorFlow, Keras, Google Cloud Platform, Folium, Power BI.
